# Shade Research brand assets

This directory is the production source of truth for the Shade Research identity.

- `shade-mark.svg`: canonical five-segment signal ring.
- `shade-lockup.svg`: canonical horizontal lockup.
- `shade-icon.png` and `shade-icon.ico`: generated application icons.

The frontend serves this directory at `/brand-assets`. Draft boards and exploration files remain in `docs/Feature Development/rebrand` and are not production dependencies.

The production palette is Midnight Blue `#18206F`, Deep Indigo `#17255A`, Paper `#F5E2C8`, Dusty Coral `#D88373`, and Signal Red `#BD1E1E`. The approved tagline is “Value in context.”
